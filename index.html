Devis groupe pour les evals navigateur.

Deux parcours calqués sur les pièges réels des sites Transavia et Air France : autocomplete, datepicker, vols en horaires, radios cachées, validation, puis un numéro de dossier déterministe.

Hop — /groupoffer

Wizard 5 étapes : recherche, grille J-1 / J / J+1, bagages, booker, groupe. Les boutons de vol affichent uniquement 6:00 - 7:20. Maximum 3 aller + 3 retour. Dates hors calendrier → « Vol aller invalide sélectionné ».

Ouvrir l’offre groupe

Flagship — /group-travel

Formulaire accordéon : Voyage → Confirmer → Groupe → Confirmer → Demandes spéciales → Envoyer ma demande. Champs invalides : « Ce champ est obligatoire. » Minimum 10 passagers.

Ouvrir la demande de voyage

Génère un PDF d’offre groupe (lettre + 3 options aller / 3 retour, prix par passager) calqué sur une offre Transavia. Même inputs → même référence GB-XXXXXX.
